# Privacy and issue reporting

[简体中文](SECURITY.md) · [English](SECURITY.en.md)

The repository does not collect OAuth tokens, cookies, API keys, passwords, or official-account authentication files. Do not paste them into issues, screenshots, public logs, or test output.

For installation or runtime problems, include the Skill version, OS, Python and CLI versions, command category, error code, and the minimum redacted metadata needed to reproduce the problem. Do not include complete tasks, model responses, business source, or official Claude session records.

The repository is public. No dedicated private-reporting channel has been established. If a report involves secrets or sensitive project content, first arrange a private channel with the maintainer; do not post the content in a public issue.

Normal permissions, explicit project scope, official-subscription authentication, and provider checks remain required. Portability must not be achieved by bypassing those checks.
