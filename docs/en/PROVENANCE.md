# Project provenance

[简体中文](../PROVENANCE.md) · [English](PROVENANCE.md)

On 2026-10-05, the maintainer explicitly confirmed that no other sources had been borrowed. The preview is organized on that basis. No external upstream repository is registered and no further upstream investigation is required.

Source was exported from the maintainer's existing `claude-bridge` and `dev-orchestrator` implementations using an allowlist. Distribution structure, tutorials, generic configuration examples, and a compatibility plan were added. The active installation and real runtime state were not replaced.
