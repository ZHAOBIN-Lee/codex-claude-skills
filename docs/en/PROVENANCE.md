# Project provenance

[简体中文](../PROVENANCE.md) · [English](PROVENANCE.md)

On 2026-10-05 the maintainer confirmed that the project source contains no code borrowed from other repositories, so there is no code upstream to list.

The source in this repository was exported by allowlist from the maintainer's existing `claude-bridge` and `dev-orchestrator` implementations. On top of that came the distribution layout, tutorials, generic config examples, and the compatibility plan. The maintainer's active installation and real runtime state weren't replaced.

The documentation's introductions and examples take writing cues from [Anthropic Skills](https://github.com/anthropics/skills), [Vercel Agent Skills](https://github.com/vercel-labs/agent-skills), [Superpowers](https://github.com/obra/superpowers), and [Baoyu Skills](https://github.com/JimLiu/baoyu-skills). No passages were copied from them.

The external products the project depends on (Claude Code, Codex Skills, and so on) are listed in [third-party notices](../../THIRD_PARTY_NOTICES.en.md), and the license is in [licensing](../../LICENSING.en.md).
