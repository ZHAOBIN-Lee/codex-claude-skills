## 现状

仓库已经公开。初版公开后做过匿名 clone 和 82 个文件的校验；下面另列本次程序修复的验证。

维护者在自己的 macOS 上，用官方 CLI 2.1.285 做过真实调用、连续会话和开发交接。这是现有实现的基线。独立朋友、新机器上的 Codex 安装、Linux／WSL、Windows 原生和 GitHub CI 都还没验证，这些见本页末尾的待办。

这次修改了 Bridge 程序和 Skills，结果与首次打包的基线分开记录。Claude 完成主要代码与说明修改，Codex 在返回后独立检查文件和运行测试。

真实调用使用官方 CLI 2.1.285、Claude.ai 订阅，完成调用的模型证据来自最终结果的 `modelUsage`。运行时拒绝的早停没有最终结果，模型与会话证据记为未取到，没有拿恢复时的旧 ID 补齐。测试在临时项目中运行，没有修改业务项目。

这些小测试的耗时不代表长任务的生成时间。权限预检只是静态检查，CLI 仍会执行自己的权限判断。Python 校验脚本所需的 PyYAML 在测试环境中未安装，四份 Skill 的 frontmatter 改用 macOS 自带 Ruby 的 YAML 解析器检查；没有因此声称原 Python 校验脚本运行成功。相对链接、JSON、必需资源、MIT 副本和公开文件中的私人资料另做检查。具体用法见[权限与失败处理](../skills/claude-bridge/references/08-permissions-and-failures.md)。
