# Architecture Decisions

仅记录用户已确认或由本轮授权支持的决策；待确认事项明确标注。不要保存隐藏推理或凭据。

## YYYY-MM-DD HH:mm Australia/Melbourne — 待填写决策标题

- Status：待确认 / 已确认 / 已由授权实施。
- Decision：待填写采用的方案。
- Reason：待填写可供后续 Agent 核对的简要理由。
- Evidence：待填写代码、测试或用户明确指令依据。
- Alternatives Rejected：待填写实际评估过的替代方案及原因；没有则写“无”。
- Scope / Approval：待填写适用项目和授权边界。
- Remaining Unknowns：待填写；无则写“无”。
