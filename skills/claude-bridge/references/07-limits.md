# 支持范围与限制

[简体中文](07-limits.md) · [English](en/07-limits.md)

这份 Skill 定义 Codex 如何调用和核对 Claude；附带 Python Bridge 负责本机执行、检查、会话元数据与交接。文本规则可移植，程序还有操作系统、官方 CLI、认证和宿主工具要求。

## 当前验证范围

| 范围 | 当前结论 |
| --- | --- |
| 作者现用 macOS 环境 | 现有 Bridge 做过真实咨询、连续 Session 和开发交接验证；最新回执规则也有真实调用证据 |
| macOS 新机器安装 | 草稿教程与打包方案，不等于已验收每台机器的安装、登录和路由 |
| Linux、WSL | POSIX 设计方向可适配；发布包仍需安装、权限、路径及真实调用验证 |
| Windows 原生 | 当前 Bridge 使用 POSIX 能力，需代码与安装适配；未宣称原生支持已完成 |
| 普通帮助与教程读取 | 由 Codex 按需读取本地参考文件，不为帮助自动调用 Claude；新安装发现路线仍需验收 |
| Team/Enterprise 或 API/第三方认证 | 当前 Bridge 的订阅检查未支持这些路线，不自动 fallback |

官方 Claude Code 支持的系统列表并不自动证明本 Bridge 在这些系统都能运行。发布时应以可复现的对应测试更新此表，区分离线测试、真实 CLI、桌面路由与关闭后恢复。

## 模型与账号

使用者需要自己的官方 Claude Code 登录和符合当前 Bridge 判断的 Claude.ai Pro/Max 订阅。安装 Skill 不附赠 Claude 账号、额度或模型权限。Sonnet/Opus 名称请求是否可用，以当前官方 CLI 与账号实际结果为准。

Bridge 不建立 API Provider，不创建 API Key，不购买额外 usage、不开启 Billing，也不在限额或失败时改走付费 API。费用关闭记录是使用者确认，不是直接读取账户 Billing 的保证。

## 权限和材料

全局安装不授权扫描任意项目、初始化 `.ai/` 或发送项目内容。每次根据明确项目、任务、材料范围和已有用户授权处理；缺失时澄清。

纯 `consult` 禁用本次内置工具和 MCP，只分析已提供材料。需要工具或改文件时进入标准流程；正常启动钩子等环境行为不应被宣传为全部禁用。

保留官方权限机制，不使用跳过权限参数或全局通配授权。私有任务文件和 Bridge 日志不进入公开交付物；日志卫生措施不能保证任意敏感输入都可公开。官方原生会话记录由官方 CLI 管理，与 Bridge 必要元数据日志分开。

## 连续使用

持续授权只来自当前聊天中的用户，并受同项目、同话题范围约束；缓存不是授权。切回 Codex、换项目或新聊天重新判断。两个 Codex 聊天可能使用同项目 Claude 会话，需要隔离时由用户明确请求新 Session。

恢复不是共享所有上下文。增量基线只覆盖规定的项目摘要、规则与 Git 快照，不自动读取全部业务文件。模型口头声称“我记得”也不替代 Session 与实际内容接续验收。

## 延迟和验收

Skill 可以减少 Codex 开始处理后的重复准备，不能截获桌面原生输入、修改 Codex 原生强度、保证固定响应时间或消除长聊天处理。CLI wall 与端到端等待需分开；本版本不提供流式首 token 计时。

现有机器上的测试结果不证明朋友的账号、系统和安装能直接通过。安装后的最小验收应包含 Skill 发现、环境检查、一次真实调用回执及需要时的连续 Session 测试。普通输出正确也不能证明业务发布、部署或付款已完成。
