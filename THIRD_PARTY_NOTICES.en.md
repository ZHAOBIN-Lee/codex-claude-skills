# External dependencies and product notices

[简体中文](THIRD_PARTY_NOTICES.md) · [English](THIRD_PARTY_NOTICES.en.md)

The maintainer confirmed that this project was not derived from other repositories. This document lists external dependencies, not upstream source-code origins.

- **Claude Code:** users install and sign in through official channels. The repository calls the local official CLI; it does not distribute its binary, accounts, or credentials. [Official setup](https://code.claude.com/docs/en/setup)
- **Codex Skills:** the project uses the host's Skill capability. It does not redistribute system Skills, other plugins, or all of the user's installed Skills. [Official Skill documentation](https://learn.chatgpt.com/docs/build-skills)
- **Python standard library and Git:** runtime and test dependencies; their binaries are not bundled.

Product names describe compatibility targets and do not imply endorsement. This project is not affiliated with Anthropic or OpenAI. Product names and trademarks belong to their respective owners.
